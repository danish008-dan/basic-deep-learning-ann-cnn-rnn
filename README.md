# basic-deep-learning-ann-cnn-rnn

# Basic Deep Learning: ANN, CNN & RNN (Python)

## 📌 Overview
This repository contains **beginner-friendly implementations** of the three core Deep Learning architectures:

- **ANN (Artificial Neural Network)**
- **CNN (Convolutional Neural Network)**
- **RNN (Recurrent Neural Network)**

Each file is **fully commented line-by-line** to help students understand **how and why** the code works.  
The goal of this repository is **learning + hands-on practice**, not just theory.

---

## 🧠 Concepts Covered

### 1️⃣ Artificial Neural Network (ANN)
- Used for **tabular / numerical data**
- Example: marks prediction based on study hours
- Core concepts:
  - Dense layers
  - Activation functions
  - Regression using ANN

📄 File: `ann_basic.py`

---

### 2️⃣ Convolutional Neural Network (CNN)
- Used for **image processing**
- Example: handwritten digit classification (MNIST dataset)
- Core concepts:
  - Convolution layer
  - Max Pooling
  - Flattening
  - Softmax classification

📄 File: `cnn_basic.py`

---

### 3️⃣ Recurrent Neural Network (RNN)
- Used for **sequence-based data**
- Example: predicting the next number in a sequence
- Core concepts:
  - Time steps
  - Sequence learning
  - SimpleRNN layer

📄 File: `rnn_basic.py`
